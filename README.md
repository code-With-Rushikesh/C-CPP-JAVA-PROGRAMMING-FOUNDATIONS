# C, C++, and Java Programming Foundations

Welcome to the **C, C++, and Java Programming Foundations** repository! This repository contains a curated collection of core programming codes, logic-building exercises, and fundamental concepts implemented across three major programming paradigms: **Procedural (C)**, **Object-Oriented (C++)**, and **Virtual Machine-Based (Java)**.

---

## 📌 Overview

This repository is designed to build a rock-solid foundation in core software development concepts. It tracks progress through basic to advanced topics in:
1. **C Language:** Procedural Programming, Memory Layout, Dynamic Memory Allocation (DMA), Pointers, Structures, and File I/O.
2. **C++ Language:** Object-Oriented Concepts (OOP), Dynamic Memory Management (`new`/`delete`), Templates, Virtual Functions, and Polymorphism.
3. **Java Language:** Platform Independence, Robust OOP Design, Multithreading, Exception Handling, Collections Framework, and Database Connectivity (JDBC).

## 🛠️ Key Topics Covered

### 🔹 1. C Language (Procedural Programming)
- **Toolchain & Memory Layout:** Preprocessor, Compiler, Linker, Loader, and Process Address Space (Stack, Heap, Data, Text).
- **Pointers & Logic Building:** Single & Multi-level pointers, Function Pointers, Callbacks, Pointer Arithmetic.
- **Dynamic Memory Allocation:** `malloc()`, `calloc()`, `realloc()`, and `free()`.
- **User-Defined Types:** Structures, Padding/Alignment, Unions, Enums, and `typedef`.

### 🔹 2. C++ Language (Object-Oriented Programming)
- **OOP Principles:** Encapsulation, Abstraction, Inheritance, and Polymorphism.
- **Memory Management:** `new` and `delete` operators, Copy Constructors, Destructors.
- **Advanced OOP:** Virtual Functions, Pure Virtual Functions, Abstract Classes, and Friend Functions.
- **Generic Programming:** Function and Class Templates.

### 🔹 3. Core & Advanced Java
- **JVM & Platform Architecture:** Compilation to Execution pipeline.
- **Object-Oriented Features:** Classes, Interfaces, Abstract Classes, Method Overriding/Overloading.
- **Multithreading:** Synchronization, Thread Lifecycle, and Runnable Interface.
- **Collections Framework:** `List`, `Set`, `Map`, Generics, and Iterators.
- **Database & I/O:** JDBC API for CRUD operations and File Handling.

## 🚀 How to Run the Code

### Prerequisites
- **C/C++:** `gcc` or `g++` compiler installed (GCC/MinGW).
- **Java:** Java Development Kit (JDK 17 or higher) installed.

### Execution Steps

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/your-username/C-Cpp-Java-Programming-Foundations.git
   cd C-Cpp-Java-Programming-Foundations
   ```

2. **Run C Program:**
   ```bash
   gcc 01_C_Programming/Pointers_and_Arrays/program.c -o program
   ./program
   ```

3. **Run C++ Program:**
   ```bash
   g++ 02_Cpp_Programming/Basic_OOP_Classes_Objects/program.cpp -o program
   ./program
   ```

4. **Run Java Program:**
   ```bash
   javac 03_Java_Programming/Core_OOP_Concepts/Program.java
   java 03_Java_Programming.Core_OOP_Concepts.Program
   ```
